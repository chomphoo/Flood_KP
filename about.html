เกี่ยวกับเว็บไซต์นี้

เว็บติดตามสถานการณ์น้ำท่วมจังหวัดกำแพงเพชร รวบรวมข้อมูลจากหน่วยงานที่เชื่อถือได้โดยอัตโนมัติทุก 30 นาที ไม่มีค่าใช้จ่าย ไม่เก็บข้อมูลส่วนบุคคล และไม่ใช้ AI ในการประมวลผล ทุกตัวเลขคำนวณด้วยเกณฑ์ที่เปิดเผยด้านล่าง

⚠️ ข้อควรทราบ

  • เว็บนี้ไม่ใช่ประกาศทางราชการ ใช้ประกอบการติดตามสถานการณ์เท่านั้น ให้ยึดประกาศของจังหวัดกำแพงเพชร ปภ. และกรมชลประทานเป็นหลัก
  • เหตุฉุกเฉิน โทร 1784 (ศูนย์ ปภ.) · 1669 (เจ็บป่วยฉุกเฉิน) · 1460 (สายด่วนกรมชลประทาน)
  • ข้อมูลอาจล่าช้าหรือคลาดเคลื่อนได้ เช่น สถานีโทรมาตรขัดข้อง หรือดาวเทียมมองไม่เห็นน้ำใต้เมฆ/ในเขตเมือง หากแหล่งใดดึงไม่ได้ เว็บจะแสดงข้อมูลชุดล่าสุดที่มี พร้อมเวลาที่อัปเดตกำกับไว้

เกณฑ์ที่ใช้

ระดับน้ำ (ร้อยละของความจุลำน้ำ ตามเกณฑ์ สสน.)

≤ 10% น้ำน้อยวิกฤต 10–30% น้ำน้อย 30–70% ปกติ 70–100% น้ำมาก > 100% ล้นตลิ่ง

ฝน 24 ชม. (เกณฑ์กรมอุตุนิยมวิทยา)

0.1–10 มม. เล็กน้อย 10.1–35 ปานกลาง 35.1–90 หนัก > 90 หนักมาก

สถานการณ์ภาพรวมจังหวัด (เลือกระดับสูงสุดที่เข้าเงื่อนไข)

  • วิกฤต – น้ำล้นตลิ่ง ≥ 3 สถานี หรือดาวเทียมพบน้ำท่วม ≥ 50,000 ไร่
  • น้ำท่วมบางพื้นที่ – น้ำล้นตลิ่ง 1–2 สถานี หรือพบน้ำท่วม ≥ 1,000 ไร่
  • เฝ้าระวัง – ระดับน้ำมาก, น้ำขึ้นเร็ว ≥ 0.5 ม./24 ชม., ฝน > 90 มม., พบน้ำท่วมเล็กน้อย หรือ GloFAS คาดการณ์เกินค่ารอบ 2 ปี
  • ปกติ – ไม่เข้าเงื่อนไขข้างต้น

ทำงานอย่างไร

  • GitHub Actions ดึงข้อมูลจากแต่ละแหล่งทุก 30 นาที ประมวลผลเป็นไฟล์ JSON แล้วเผยแพร่บน GitHub Pages โดยอัตโนมัติ เบราว์เซอร์ของผู้ชมโหลดเพียงไฟล์ที่เตรียมไว้ จึงเร็วและไม่เป็นภาระต่อระบบของหน่วยงานต้นทาง
  • ทุกวันหลังเที่ยงคืน ระบบบันทึกสรุประดับน้ำรายวันไว้ใน branch data ของ repository เพื่อสะสมเป็นสถิติย้อนหลัง
  • พื้นที่น้ำท่วมจากดาวเทียมถูกรวมเป็นช่องหกเหลี่ยม (H3 ขนาดประมาณ 0.7 ตร.กม.) เพื่อให้แผนที่เบาและเปิดบนมือถือได้ลื่น
  • คาดการณ์ GloFAS เป็นแบบจำลองระดับโลกความละเอียดประมาณ 5 กม. เหมาะกับการดูแนวโน้มของแม่น้ำปิงสายหลัก ไม่ใช่ตัวเลขที่ตรงกับสถานีจริง
  • ซอร์สโค้ดเปิดเผยที่ github.com/chomphoo/Flood_KP
